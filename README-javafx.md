# Cinema Booking: Docker + JavaFX

## Запуск

Требуются Docker Desktop (запущен), Docker Compose, JDK 25 для JavaFX-клиента и Maven 3.9+. Docker сам собирает Spring Boot с JDK 26; локальная установка JDK 26 для сервера не нужна.

Из корня проекта в PowerShell:

```powershell
docker compose up -d --build --wait
docker compose ps
```

После запуска API доступен на `http://127.0.0.1:8080/api/movies`. PostgreSQL опубликован только на `127.0.0.1:5433`, Redis доступен лишь контейнерам. Compose использует локальный `.env` с паролем PostgreSQL. Если `.env` отсутствует, скопируйте `.env.example` в `.env` и замените пароль. Данные БД и Redis хранятся в именованных томах.

### Демонстрационные данные и вход

Миграция `007-demo-data.sql` добавляет 6 фильмов, 3 зала по 40 мест, 8 сеансов, 3 бронирования и пользователей двух ролей. Миграция `008-more-demo-movies-and-sessions.sql` переносит исходные демонстрационные сеансы на даты не раньше 30 октября 2026 года, сохраняя бронирования, и добавляет ещё 7 фильмов и 11 сеансов. Среди новых фильмов — «Интерстеллар», «Начало», «Тёмный рыцарь», «Аватар», «Титаник», «Матрица» и «Колобок». Длительности, описания и возрастные рейтинги служат демонстрационными данными. На уже созданной базе новая миграция применится после пересборки и перезапуска backend. Liquibase выполняет каждую миграцию один раз; при последующих запусках данные сохраняются.

### JavaFX вне Docker

В отдельном терминале:

```powershell
cd .\javafx-client
mvn javafx:run
```

По умолчанию клиент обращается к `http://127.0.0.1:8080/api`. Адрес можно изменить в верхней строке приложения. В гостевом режиме доступны просмотр, поиск, фильтры, сортировка, статистика и CSV. Для изменения данных войдите как администратор. Для экспорта сначала настройте поиск и фильтры, затем нажмите «Экспорт CSV»: сохраняется именно показанный список в текущем порядке, а путь выбирается через системное окно.

Главная сущность — фильм: полный CRUD. Сеансы также поддерживают CRUD; при создании или изменении сеанса фильм и зал выбираются из списков. Залы можно добавлять, изменять и удалять в правой части вкладки сеансов. Сортировка работает нажатием на заголовки таблиц. Два фильтра фильмов — возрастной рейтинг и длительность. Отдельная вкладка показывает показатели по фильмам и сеансам.

Во вкладке «Сеансы и залы» поиск по фильму принимает часть названия без учёта регистра; пустая строка показывает все фильмы. Для зала есть пункт «Все залы». Также можно отфильтровать показы по начальной и конечной дате (обе включительно) и времени начала: до 12:00, с 12:00 до 17:59 или с 18:00. Кнопка «Очистить поиск» очищает название фильма, а «Сбросить время» — даты и время суток. Чтобы забронировать место, войдите в учётную запись, выберите будущий сеанс в таблице, затем свободное место и нажмите «Забронировать». Во вкладке «Бронирования» отображаются только бронирования текущего пользователя; выбранное бронирование можно отменить до начала сеанса. Кнопка «Обновить мои бронирования» повторно загружает список с сервера. Например, у `demo_anna` уже есть два бронирования, а у `demo_ivan` — одно.

Во вкладке «Статистика» клиент подсчитывает число сеансов по каждому фильму через `HashMap<Long, Integer>` (`getOrDefault`, `put`, `containsKey`, `get`). Отдельный `List<Movie>` фильтруется и сортируется (`removeIf`, `sort`, `isEmpty`, `get`, `size`), чтобы показать фильм с наибольшим числом сеансов. Сортировка списка статистики не меняет порядок основной таблицы.

### Где искать код клиента

`CinemaApp` запускает JavaFX, а `main.fxml` собирает окно из отдельных файлов вкладок. `MainController` отвечает за подключение, вход и общую загрузку данных. Контроллеры `MovieTabController`, `SessionTabController` и `BookingTabController` управляют своими вкладками. Внутри вкладки сеансов `HallPaneController` работает с залами, а `SessionBookingController` — с местами и бронированием.

`CinemaApi` содержит операции бэкенда, `ApiTransport` отправляет HTTP-запросы и хранит cookie. Фильтры таблиц работают в контроллерах над уже загруженными списками. `MovieStatistics` считает показатели, `MovieCsvExporter` записывает CSV. Проверка полей форм находится в `MovieService` и `SessionService`.

### IntelliJ IDEA

Если открыт корень `cinema-booking`, выполните **Reload All Gradle Projects** в окне Gradle. В проекте появится модуль `javafx-client`; его `src/main/java` и `src/main/resources` станут исходниками. Убедитесь, что Project SDK — JDK 25 или 26. Запускайте `ru.cinema.client.CinemaApp.main()` через зелёную кнопку рядом с `main` либо задачу Gradle `javafx-client > Tasks > application > run`. Maven-команда `mvn javafx:run` в каталоге клиента также остаётся доступной.
## Остановка и данные

```powershell
docker compose down
```

Обычное `down` сохраняет тома и данные PostgreSQL. Не используйте `down -v`, если хотите сохранить БД.

## Проверка сборки клиента

```powershell
cd .\javafx-client
mvn clean compile
```

Клиент работает через существующий REST API Spring Boot. Прямого JDBC-подключения, указанного для собственной КР №2 в HTML-задании, здесь нет по выбранной архитектуре проекта. В состав Compose клиент не входит.
